课时2：计算机简介 20:02     Will学习通过
学习笔记:
## 1,计算机是什么
    计算机就是用来计算的机器。
    目前来说，计算机只能根据人类的指令来完成各种操作，人让它干嘛它就得干嘛。
所以我们学习计算机，就是学习如何控制计算机。
## 2，计算机组成：硬件 + 软件 
    硬件： 看得见摸得着
    软件： 系统软件 + 应用软件，看得见摸不着，软件负责控制计算机中的硬件
## 3, 计算机的使用方式
    必须通过软件来对计算机完成各种操作，但是注意，软件中并不是所有的功能都对用户开放。

    用户需要调用软件提供的接口(Interface， 有时也称 交互界面)来操作计算机。

    用户界面分成两种: TUI(文本交互界面) 和 GUI(图形化交互界面)

课时3：命令行简介 17:07     Will学习通过
学习笔记:
## 1,windows的命令行
    命令行就是文本交互界面，通过命令行可以使用一个一个的指令来操作计算机。
    
    任何计算机的操作系统中都包含命令行(windows,linux,macOS)

    命令行有多个不同的名字： 命令行、命令行窗口、DOS窗口、CMD窗口、Shell、终端、Terminal、命令提示符
    
    1，如何进入到命令行：win键 + R 出现运行窗口，输入 cmd , 按 Enter
    2, 命令行的结构: 
        - 版本及版权声明 (一般没什么用)
            Microsoft Windows [版本 10.0.26100.6584]
            (c) Microsoft Corporation。保留所有权利。
        - 命令提示符
            C:\Users\Administrator>
                分解
                C: 
                    - 当前所在的磁盘的根目录
                    - 可以通过 x: 来切换盘符 (比如： C: , D: )
                \Users\Administrator   (用户的家目录)
                    - 当前所在的磁盘的路径
                    - cd 来切换目录
                >
                    - 命令提示符，在大于号(>)后边可以直接输入指令

课时6：Path环境变量 15:36     Will学习通过
学习笔记:
## 1，Path环境变量
    Path环境变量中保持的是多个路径

    当我们在命令行中输入一个命令(或访问一个文件)时，系统会首先在当前目录下寻找，如果找到了则直接执行或打开;
    如果没有找到,则会依次去path环境变量的路径中去寻找;直到找到为止。(问题：多个路径都有这个文件 abc.txt ，打开哪个  我的理解: 从Path路径配置从前往后找该文件 。 20250913 得到验证 就是这样 从前往后 找)
    如果path环境变量中的路径都没有找到，则报错：  'xxx.txt' 不是内部或外部命令，也不是可运行的程序或批处理文件。

    tips: 我们可以将一些经常需要访问的文件和程序的路径，添加到Path环境变量中，这样我们就可以在任意位置访问到这些文件了。

    注意： 
        1，修改完 环境变量 \ Path路径后 需要 重启命令行窗口，才能生效。
        2，如果环境变量中没有Path，可以手动添加
        3，Path环境变量不区分大小写， PATH 、Path 、pAtH、path
        4，多个路径之间 使用 分号 ; 隔开
